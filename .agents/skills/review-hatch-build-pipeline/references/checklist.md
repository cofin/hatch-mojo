# Hatch Build Pipeline Review Checklist (`HBP-01..HBP-08`)

| Rule ID | Severity | Check | Target Surface |
| --- | --- | --- | --- |
| `HBP-01` | `Critical` | **Slotted Frozen Value Objects**: Every `@dataclass` in `hatch_mojo/` declares `@dataclass(slots=True, frozen=True)` and uses immutable `tuple[T, ...]` for sequence fields so `slotscheck` passes and parallel jobs cannot mutate shared config. | `hatch_mojo/*.py` |
| `HBP-02` | `Critical` | **Config Cross-Field & Legacy Validation**: `emit == "python-extension"` requires non-empty `module` and rejects `install`; all other `EmitType` values (`shared-lib`, `mojoc`, `object`, `executable`) require explicit `install.kind` (`package`, `data`, `scripts`, `root`, `force-include`) and non-empty `install.path` (except `root`); legacy `static-lib`, `.🔥`, `📦`, and `.mojopkg` raise `ValueError`; inactive `target_name` returns `jobs=()` without raising. | `hatch_mojo/config.py` |
| `HBP-03` | `Critical` | **Wheel Purity & `wheel-tag` Policy**: When `target_name == "wheel"`, `register_artifacts` leaves pure `.mojoc`/`object`-only wheels pure unless an explicit PEP 425 `wheel_tag` is set; when any job has `emit not in {"object", "mojoc"}`, it sets `build_data["pure_python"] = False` and honors `wheel_tag` (`"auto"` &rarr; `"infer"` if `python-extension` exists else `"py3-none"`, `"infer"`, `"py3-none"` via `resolve_host_platform_tag`, or explicit `<py>-<abi>-<plat>`). | `hatch_mojo/artifacts.py` |
| `HBP-04` | `Critical` | **Mojo `1.2+` CLI & Darwin Header Padding**: `build_command` invokes `mojo precompile` without `--emit` or linker flags for `mojoc`, maps `executable` to `mojo build --emit exe`, and preserves `["-Xlinker", "-headerpad_max_install_names"]` on `darwin` for `python-extension`, `shared-lib`, and `executable` jobs. | `hatch_mojo/compiler.py` |
| `HBP-05` | `Important` | **Topological Determinism, `{stem}` Globs & Cycle Safety**: `plan_jobs` and `plan_jobs_leveled` propagate `config.build_dir`, substitute `{stem}`, rewrite `depends_on` across expanded globs and `excluded_jobs`, reject colliding output or install targets, and detect dependency cycles with `ValueError`. | `hatch_mojo/planner.py` |
| `HBP-06` | `Important` | **Unidirectional Module Dependencies & `finalize` Lifecycle**: Lower pipeline modules (`types`, `config`, `planner`, `compiler`, `runtime`, `artifacts`, `cleaning`) never import `hatch_mojo.plugin` or `hatch_mojo.hooks`, and `clean_after_build` executes in `MojoBuildHook.finalize` (`include_editable=False`) rather than `initialize`. | `hatch_mojo/*.py` |
| `HBP-07` | `Important` | **Public-Seam Canonical Tests**: Tests live in the matching `tests/test_<module>.py` or `tests/test_integration_*.py` file, exercise public functions with real `tmp_path` inputs, and avoid mocking the System Under Test or creating standalone `test_*remediation*.py` / `test_*audit*.py` files. | `tests/*.py` |
| `HBP-08` | `Minor` | **Typing & Docstring Hygiene**: Code uses PEP 585 built-in generics (`list`, `dict`, `tuple`), PEP 604 `T | None` unions, and Google-style docstrings without inline `#` restatement comments. | `hatch_mojo/*.py`, `tests/*.py` |
