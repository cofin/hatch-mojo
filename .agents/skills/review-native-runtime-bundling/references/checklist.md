# Native Runtime Bundling Review Checklist (`NRB-01..NRB-08`)

| Rule ID | Severity | Check | Target Surface |
| --- | --- | --- | --- |
| `NRB-01` | `Critical` | **Ad-Hoc Re-Signing After Mach-O Mutation**: Every code path mutating a Mach-O dylib, extension, executable, or editable binary (`_patch_macos_dylibs`, `_patch_macos_extension`, `_patch_rpath`, `patch_editable_runtime`) calls `_resign_ad_hoc` (`codesign -s - -f`) after the final load-command edit. | `hatch_mojo/runtime.py` |
| `NRB-02` | `Critical` | **Idempotent `install_name_tool` & Surfaced `stderr`**: All `install_name_tool` invocations go through `_run_install_name_tool` with `capture_output=True, text=True`, surfacing `stderr` in `RuntimeError` on failure and handling idempotency via `ignore_errors` substrings (`already contains LC_RPATH`, `no LC_RPATH found`). | `hatch_mojo/runtime.py` |
| `NRB-03` | `Critical` | **`LC_RPATH`-Scoped Stripping & System Lib Preservation**: `_strip_absolute_rpaths` tracks `cmd LC_RPATH` load commands strictly (never `LC_LOAD_DYLIB`), strips non-`@` RPATHs from both staged dylibs and compiled Mach-O outputs, sets `-id @rpath/<name>` on `shared-lib` outputs, and skips rewriting `/usr/lib/*`, `/System/*`, `@rpath/*`, and `@loader_path/*`. | `hatch_mojo/runtime.py` |
| `NRB-04` | `Important` | **Compiler-Matched SDK Discovery & Dynamic BFS Resolution**: `discover_modular_lib` prioritizes `MODULAR_LIB_DIR` and resolved `mojo_bin` ancestors/wrapper-venvs before ambient `mojo._package_root`/`find_spec`, and `_resolve_modular_dependencies` walks `ldd` (including `not found` basenames) / `otool -L` dynamically with guaranteed `_sentinel()` inclusion across `python-extension`, `shared-lib`, and `executable` jobs. | `hatch_mojo/runtime.py` |
| `NRB-05` | `Important` | **Writable Staged Libraries Before Patching**: Copied SDK libraries in `<pkg>.libs/`, `data/<dist>.libs/`, and `editable.libs/` receive `stat.S_IWUSR` (`chmod`) prior to `patchelf` or `install_name_tool` execution. | `hatch_mojo/runtime.py` |
| `NRB-06` | `Important` | **Accurate `platlib`, `.data/`, & Editable RPATHs**: `_compute_relative_rpath` computes exact relative paths from install targets (including depth-0 `_core.so` &rarr; `$ORIGIN/<pkg>.libs` and `.data/scripts/` &rarr; `$ORIGIN/../lib/<dist>.libs`), while `patch_editable_runtime` embeds persistent SDK paths directly and stages `editable.libs` when `_is_ephemeral_sdk` is `True`. | `hatch_mojo/runtime.py` |
| `NRB-07` | `Important` | **Apache-2.0 Attribution Integrity**: `_write_license_notice` emits `Apache-2.0 WITH LLVM-exception` attribution in `NOTICE.mojo-runtime` (adding MAX Section 1.5 terms only when `_is_max_only_library` matches bundled files) and copies `LICENSE.mojo-runtime` when `modular/LICENSE` exists. | `hatch_mojo/runtime.py` |
| `NRB-08` | `Important` | **Cross-OS Boundary Test Coverage**: Changes to `runtime.py` include `linux`, `darwin`, and (where applicable) `win32` coverage in `tests/test_runtime.py` mocking only `subprocess.run` / `sys.platform` while staging real files in `tmp_path`. | `tests/test_runtime.py` |
