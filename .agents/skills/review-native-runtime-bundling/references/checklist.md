# Native Runtime Bundling Review Checklist (`NRB-01..NRB-08`)

| Rule ID | Severity | Check | Target Surface |
| --- | --- | --- | --- |
| `NRB-01` | `Critical` | **Ad-Hoc Re-Signing After Mach-O Mutation**: Every code path mutating a Mach-O dylib or extension with `install_name_tool` calls `_resign_ad_hoc` (`codesign -s - -f`) after the final load-command edit so Apple Silicon loaders do not kill the process. | `hatch_mojo/runtime.py` |
| `NRB-02` | `Critical` | **Idempotent `install_name_tool` & Surfaced `stderr`**: All `install_name_tool` invocations go through `_run_install_name_tool` with `capture_output=True, text=True`, surfacing `stderr` in `RuntimeError` on failure and handling idempotency via `ignore_errors` substrings (`already contains LC_RPATH`, `no LC_RPATH found`) rather than `otool` pre-check regexes. | `hatch_mojo/runtime.py` |
| `NRB-03` | `Critical` | **Residual SDK RPATH Stripping & System Lib Preservation**: `_patch_macos_dylibs` strips non-`@`-prefixed `LC_RPATH` entries (`_strip_absolute_rpaths`) and skips rewriting `/usr/lib/*`, `/System/*`, `@rpath/*`, and `@loader_path/*` references. | `hatch_mojo/runtime.py` |
| `NRB-04` | `Important` | **Dynamic BFS Resolution + Sentinel Seed**: Runtime dependencies are discovered recursively via `_resolve_modular_dependencies` (`ldd` / `otool -L`) filtered by `modular_lib` existence plus guaranteed `_sentinel()` inclusion, never hardcoded library lists. | `hatch_mojo/runtime.py` |
| `NRB-05` | `Important` | **Writable Staged Libraries Before Patching**: Copied SDK libraries receive `stat.S_IWUSR` (`chmod`) prior to `patchelf` or `install_name_tool` execution so read-only virtualenv/container SDK files do not cause `PermissionError`. | `hatch_mojo/runtime.py` |
| `NRB-06` | `Important` | **Module-Depth Relative RPATHs**: `_compute_extension_rpath` computes `".."` segments from `len(module.split(".")) - 1` using `$ORIGIN` on Linux and `@loader_path` on `darwin`, targeting `<top_pkg>.libs`. | `hatch_mojo/runtime.py` |
| `NRB-07` | `Important` | **Redistribution Notice Integrity**: `bundle_runtime_libs` writes sorted `NOTICE.mojo-runtime` (and copies `LICENSE.mojo-runtime` when `modular/LICENSE` exists) into `<pkg>.libs/` and registers both in `force_include`. | `hatch_mojo/runtime.py` |
| `NRB-08` | `Important` | **Cross-OS Boundary Test Coverage**: Changes to `runtime.py` include `linux`, `darwin`, and (where applicable) `win32` coverage in `tests/test_runtime.py` mocking only `subprocess.run` / `sys.platform` while staging real files in `tmp_path`. | `tests/test_runtime.py` |
